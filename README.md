# PC Shop Empire

PC Shop Empire is a computer-store management simulation for Windows and macOS. Build compatible PCs, manage inventory, serve customers and grow the business.

## Downloads

Use the [v1.1.6 release page](https://github.com/cixanla/PC-Shop-Empire/releases/tag/v1.1.6):

- Windows 64-bit: setup `.exe`
- macOS on Apple Silicon (M1, M2, M3 and M4): `.dmg` or `.zip`

The browser edition and full guide are available on [cixanla.com/pc-shop-empire](https://cixanla.com/pc-shop-empire).

## macOS note

The current macOS build is ad-hoc signed for local testing, but it is not yet notarized with an Apple Developer ID. macOS may therefore show a Gatekeeper warning on another computer.
